## 🧭 Convenção de nomes

Cada exercício segue o padrão `exNN_nome_do_exercicio.c`:

- `ex05_calculadora_com_funcoes.c`
- `ex12_media_da_turma.c`

## 🛠️ Como compilar e executar

```bash
gcc ex05_calculadora_com_funcoes.c -o ex05 -Wall -Wextra
./ex05
```

No Windows, use `ex05.exe` no lugar de `./ex05`.
